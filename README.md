# homepage

This repository contains a simple static website for GitHub Pages.

## Pages
- `index.html` — home page
- `about.html` — about page

## GitHub Pages setup
1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to Pages.
4. Set the source to the default branch (`main` or `master`) and the root folder `/`.
5. Save the settings and wait for GitHub to publish the site.

The site will be available at:
`https://dhuynh-ecc.github.io/homepage/`
